# Dual-Write-Error
This repository explores the Dual Write problem in APIs, explaining its causes, demonstrating how the issue can occur, and providing branches to inspect different failure scenarios. It also presents a solution using the Outbox Pattern to ensure reliable and consistent data processing.  
- Language: C# 
- Framework: .NET
